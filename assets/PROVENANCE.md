evidence supports redistribution under the project [MIT license](../LICENSE).

the file is embedded in released binaries and must not be treated as covered by
the project MIT grant until the missing record is supplied or the artwork is
replaced. This table is the single maintainable record; keep it accurate when
artwork is added or replaced, and keep

## Why the unclear sets block a wholly cleared binary

`assets/system/**`, `assets/boot/**` and `assets/native/**` are embedded into
the released executables with `include_bytes!`. `assets/branding/**` is not
embedded (its only code reference is test-only), but it ships in the source
archive and is regenerable material derived from the same unresolved masters.
Resolution requires one of:

1. a dated owner statement naming the supplied references and licensing them
   under MIT;
2. written permission or a license from the actual creator of the supplied
   logo sheet, boot storyboard and cave scene; or
3. replacement of the unresolved artwork with project-owned or tool-generated
   material whose terms are recorded here.

Record the tool name/version and the reference files' SHA-256 when resolving.
Do not describe the repository or its binaries as wholly MIT-covered while any
row above remains **unclear**.
