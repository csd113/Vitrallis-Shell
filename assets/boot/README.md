# Startup keyframes

Five pre-rendered 480×272 PNG layers are embedded only in the startup player. `clean`,
`subtle`, `cyan`, and `full` are composed from the aligned crystal masters;
`scene` is the cave background with its central crystal removed. The full-energy
crystal remains the same transparent layer, at the same coordinates, while the
cave and original lettering fade in behind it.

See [branding preparation](../branding/README.md) and
[playback and memory limits](../../docs/visual-design.md). Artwork never becomes
the default background of normal application or system screens.
