# Original Vitrallis utility icons

Terminal, Notepad and Files are original geometric artwork created for this
workspace. Each SVG has a 128×128 viewBox and transparent background. The 128×128
RGBA PNGs are the embedded launcher assets, matching the existing icon decoder.
Mint outlines, dark panels and simple silhouettes form one family. No third-party
artwork, icon library or external asset request is used.

Edit the SVG sources and rasterize them to PNG with an SVG-capable local tool.
SVG rasterization is a development step, not an installed runtime dependency.

Project-owned icons are covered by the root [MIT license](../../LICENSE).
